Manual de Usuario & Ergonomía

1. Pantalla Principal: Hub de Proyectos

En la pantalla de inicio visualizas todos tus proyectos con su UUID identificador único. Haz doble clic en una tarjeta o presiona Abrir Proyecto para acceder a su espacio de trabajo.

2. Aislamiento Estricto de Doble Repositorio

Cada proyecto tiene dos repositorios: app/ (código y API) y governance/ (OKF y rama huérfana). El contexto de un proyecto jamás se cruza con el de otro.

3. Leases de Tareas en Kanban

Al tomar una tarea en proceso, se reserva un candado de lease temporal (ej. 30 min) para evitar colisiones con otros agentes en el enjambre.

Atajos de Teclado Globales

Ctrl + P Crear Nuevo Proyecto en Hub
Ctrl + N Nueva Tarea (dentro del proyecto)
Ctrl + D Alternar Modo Claro / Oscuro
