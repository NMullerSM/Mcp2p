# MCP²P Brand Assets

Repositorio oficial de assets de marca y diseño para **MCP²P**.

## Estructura de Carpetas

- [`core/`](core/): Archivos maestros vectoriales en SVG puro (imagotipos dark/light, escudo con/sin fondo y wordmark).
- [`favicons/`](favicons/): Favicons optimizados (`favicon.ico`, PNGs 16px, 32px, 48px, 180px, 192px, 512px).
- [`png/`](png/): Renders PNG de alta resolución (800w, 512px, 1024px).
- [`social/`](social/): Cabeceras oficiales (GitHub social preview 1280×640, OG Image 1200×630).
- [`preview.html`](preview.html): Galería visual interactiva para ver todos los assets en local.
- [`BRAND_SYSTEM.md`](BRAND_SYSTEM.md): Manual de identidad corporativa y tokens de diseño.

## Uso en el código
Los iconos del frontend y del escritorio salen de `core/`, `png/` y `favicons/`; el manual de identidad es `BRAND_SYSTEM.md`.
