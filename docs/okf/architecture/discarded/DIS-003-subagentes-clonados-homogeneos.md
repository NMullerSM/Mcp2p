# DIS-003: Forzar Modelos y Prompts Idénticos en Todos los Nodos

## Alternativa Evaluada
Obligar a que todos los desarrolladores del enjambre utilicen exactamente el mismo modelo LLM y las mismas skills.

## Razones del Descarte
1. Elimina la diversidad de criterio y la fricción creativa sana entre modelos.
2. Limita la soberanía del desarrollador local para configurar su entorno.
3. Se preserva el Core Compartido en OKF permitiendo libertad y asimetría local.
