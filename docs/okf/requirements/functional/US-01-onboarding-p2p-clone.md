# US-01: Onboarding P2P con Clonado Automático

Como desarrollador que recibe un enlace de invitación `mcp2p://join?token=...`, quiero que la aplicación verifique la firma criptográfica y clone automáticamente los repositorios de código y gobernanza para empezar a colaborar sin configuración manual.
