# US-03: Validación de PRs y Tiempo de Gracia

Como autor de una propuesta, quiero que mi agente prepare la PR vinculada al OKF y que, si mi compañero no puede revisar dentro de su tiempo de gracia acordado, los cambios se auto-fusionen para no frenar el proyecto.
