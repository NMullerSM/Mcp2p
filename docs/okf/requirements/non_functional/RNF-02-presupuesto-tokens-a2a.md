# RNF-02: Presupuesto Predecible de Tokens en Conversaciones A2A

- Las sesiones de diálogo entre agentes deben compactarse obligatoriamente cada 3 turnos.
- La ventana activa devuelta al agente no debe exceder 1,500 tokens de contexto independientemente de la duración del debate.
